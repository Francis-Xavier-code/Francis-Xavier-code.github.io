# 工具推荐

由于本人只有Windows的生产电脑，所以此篇文章只讲本人使用过的Windows端工具。

在此帖子上，我会介绍生产力工具的使用场景、功能，同时附带使用界面截图来让你快速了解这是一个什么样的工具。

## 1.1 [NeatDownloadManager](https://www.neatdownloadmanager.com/index.php/en/)——多线程下载工具

在日常下载文件的时候，通常会因为网络波动而烦恼，有时候即使你家的WiFi上行宽带非常高，也难免会出现一些`网络波动`，如果在下载一个软件的时候突然断开，以浏览器的下载来说必须重新下载，这非常消耗我们的生产时间。而这个工具支持`断点续传`（你关机和重启后还能继续下载），支持`分段下载`( 将一个文件拆成许多份然后进行下载，全部下载后进行合并) 。

## 1.2 [LightShot](https://app.prntscr.com/zh-cn/index.html)——好用的截图软件

在日常截图中，Windows上自带的截图不是不好使用，是功能`过于冗余`，一些图标有时候还弄混淆，甚至一些只能保存到`剪贴板`，这就导致了一些截图需要粘贴在一些特殊的地方然后使用“另存为”来进行保存。

而这款软件支持的功能都是`必需品`，不得不借鉴。

![image](6.png)

> 简洁明了是它的强项，快速保存是它的优势

## 1.3 [微信输入法](https://z.weixin.qq.com/)——个人认为最强最好用的输入法

在Windows电脑上，我们登录一些网站经常要用到手机上的验证码，这个时候这个输入法的功能就体现出来了，它可以支持多端`剪贴板秒同步`，而且词语侯换框非常`有质感`，并且支持多端传输文件，再也不用打开占用内存的某Q某V来进行*“我的电脑”*或者建群传送了（关键是`原图直传`，不压缩图片清晰度。

## 1.4 [GitHub Stars Manager](https://gsm.aminta.top/)——GitHub Stars聚合查看器

在日常生活中，我们经常会收藏一些实用的`GitHub仓库`，但是随着时间的积累，仓库越来越多，使用网页查找某个Star过的仓库得翻半天，这时候这个软件的功能就体现出来了。

它通过你的`GitHub API`进行同步你的`GitHub Star`的仓库，结合搜索以及AI来帮你整理你的仓库，这是一个令人惊讶的项目，完美解决了日常上网中的需求点。
